Important engineering note

This is a browser-based reduced-order educational model, not a validated electromagnetic finite-element solver. The 3D geometry is illustrative. Results are suitable for learning, parameter sweeps and early concept comparison only—not for safety-critical design, certification, or claiming measured motor performance.

For credible R&D, calibrate against a datasheet, dynamometer measurements, MATLAB/Simulink, Motor-CAD, JMAG, ANSYS Maxwell, or another validated tool. The current model uses simplified steady-state torque/speed curves and lumped thermal estimation.

Runs locally in a modern browser. Three.js is loaded from a CDN for 3D display; charts and CSV export are implemented in-page. CSV files open in Excel. No API key is required.
